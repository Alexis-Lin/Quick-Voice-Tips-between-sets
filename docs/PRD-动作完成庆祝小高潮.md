## 1. 背景与目标

完成一组动作是训练里最高频的"成就时刻"，但当前缺少一个统一、有仪式感、又不腻的即时反馈。
本功能把"完成 → 奖励 → 继续"做成一个**分级的小高潮**。

**目标**
- G1：完成瞬间给出**即时、愉悦**的正反馈（无空窗）。
- G2：**分级**——不同完成情境（打断/达标/破纪录、一组/一课）强度与语气不同。
- G3：**一致又有惊喜**——品牌恒定层保证辨识度，变化层（话术/强度）保证新鲜。
- G4：**不打断心流**——普通档轻快可跳过，只有大成就才占全屏。

**非目标**
- 不做课后完整报告（属[组间语音 PRD 需求二]）。
- 不在本期替换音效/TTS 供应商（音效来源见 [AI prompt 文档](./sfx-ai-prompts.md)）。

---

## 2. 体验流程（三步）

```
① 技术确认        ② 庆祝小高潮页                       ③ 跳转
最后一次动作/最后  ┌───────────────────────────┐        按上下文：
一秒的动画+UI播完  │ UI(文字+动效+洒花)         │  中间组 → 组间报告/休息
（含逐次“咚咚”音） │ + 音效(完成/庆祝)         │  末组   → 课程总结
                   │ + 人声(教练鼓励一句)      │
                   └───────────────────────────┘
```

- **①→② 的交接**：末次确认动画**播完**才进庆祝页，避免抢拍。逐次「咚咚」确认音属于①，不进②。
- **② 的触发**：绑定后端**完成事件**（见 §7）；打开时**表现/PB 数据已就绪**，可据此定档。
- **②→③**：目标屏由上下文决定（组间报告 or 课程总结）。庆祝页可**溶解转场**进入下一屏。

## 2.5 载体形态（两个端）

庆祝页要同时适配两种差异极大的屏幕，**共用恒定品牌层，各自适配布局**：

| 端 | 尺寸/形状 | 角色 | 布局要点 |
|---|---|---|---|
| **设备端（主）** | **纯圆 466 × 466** | 训练中用户直视的主屏，小高潮的主战场 | 无四角；内容收进**圆内安全区**；构图径向/居中；洒花裁进圆内；可用**边缘光环**做庆祝强化 |
| **手机 App** | 竖向方屏 | 陪伴/回看；空间更充裕 | 可承载更多（数据卡、更大洒花场）；字标可更大；可展开统计揭示 |

**圆屏关键约束（466×466）**
- **安全区**：圆内接正方形边长 ≈ 直径 / √2 ≈ **329px**（约 70% 直径）。所有文字/徽章必须落在此范围内，否则被圆边裁掉。
- **径向构图**：字标居中，徽章/副标在其上下短距排布；避免长文本换行超宽。
- **洒花裁切**：粒子在圆形 clip 内绘制，飞出圆边即隐，不露方角。
- **边缘光环**：圆屏没有"全屏铺满"的概念，用**沿圆边点亮的 neon 光环**替代方屏的全屏爆发，作为 T3/T4 的强化手段。
- **字号更克制**：圆屏可视高度有限，字标较手机端小一档（原型：圆 ~46px vs 手机 ~52px）。

**两端一致 / 差异原则**
- 一致（L0）：荧光绿×黑、字标字体、洒花样式、声音签名、教练人声——两端完全相同。
- 差异（布局层）：安全区、字号、洒花铺展范围、T3/T4 的"全屏 vs 光环"强化方式。
- **人声/音效两端一致**（由设备扬声器/手机分别播放），只有视觉按形态适配。

> 交互原型已支持「设备端·466 圆 / 手机 App」切换，可直接对比两端布局。

## 3. 分级模型：2 维 → 5 档

### 3.1 两个维度
- **维度 A · 完成质量**：打断/未达标 → 达标 → 破纪录（达标之上的特级）
- **维度 B · 完成层级**：一组/一个动作 → 整节课

> ⚠️ 语气拐点：**"打断/未达标"不做庆祝，做"平静肯定/安抚"**。大洒花配没做满的组会显空洞。

### 3.2 五档强度阶梯

| 档 | ID | 触发（质量 × 层级） | 语气 |
|---|---|---|---|
| **T0** | `SET_ACK` | 一组 · 打断 / 未达标 | 平静肯定、安抚 |
| **T1** | `SET_DONE` | 一组 · 达标 | 轻快庆祝 |
| **T2** | `SET_HIGHLIGHT` | 一组 · 破纪录 / 表现优秀 | 高光、兴奋 |
| **T3** | `COURSE_DONE` | 整节课 · 完成 | 大庆祝、仪式感 |
| **T4** | `COURSE_GRAND` | 整节课 · 多 PB / 高完成度 | 史诗、满贯 |

## 4. 三元素 × 分级 主矩阵

| 档 | UI 文字 | UI 动效 / 洒花 | 音效 | 人声（教练话术池） |
|---|---|---|---|---|
| **T0** | "已记录" / "Logged" | 极简淡入 + 勾选，**不洒花** | 轻确认音（低音量） | `CELEBRATE_SET_ACK`：安抚中性 |
| **T1** | **"Complete"**（锚） | 字标 scale-in + 小粒子 pop | 完成音（类2·琶音） | `ENCOURAGE_PERFORMED_NOT_WELL`*（中性鼓励口径） |
| **T2** | "Complete" + **PB 徽章** | 更大爆发 + 金色点缀 + 徽章动画 | 完成音 + sparkle / 短掌声 | `ENCOURAGE_PERFORMED_WELL` / `ENCOURAGE_RECORD_BREAKING` |
| **T3** | **"Course Complete"** | 全屏 + 持续洒花 + 数据揭示 | 鼓掌庆祝（类3） | `CELEBRATE_COURSE_DONE`（新） |
| **T4** | "Perfect Course" | 全屏加强 + 分层 + 更长 | 类3 大组合 | `CELEBRATE_COURSE_GRAND`（新） |

\* T1 复用现有 `ENCOURAGE_PERFORMED_NOT_WELL` 分类，但话术按"中性鼓励"而非"批评"口径填。

---

## 5. 一致性：恒定层 vs 变化层

| | 内容 | 作用 |
|---|---|---|
| **恒定层 L0** | 荧光绿×黑视觉语言、"Complete" 字标字体、洒花基础样式、**核心声音签名(sonic logo)**、教练人声人格 | 一致性 / 品牌记忆 |
| **变化层 L1（有意义）** | 强度/规模、文字、音效丰富度 —— **随档位变** | 有意义的惊喜（破纪录就更炸） |
| **变化层 L2（轮换）** | 具体那句鼓励话术、细微粒子/配色变体 —— **每次洗牌换** | 防腻、新鲜 |

原则：**惊喜只在受控变体内发生**（token/配置驱动），再怎么变也"像一套"。

## 6. 每档时长与交互规格

| 档 | 时长 | 呈现 | 结束方式 | 可跳过 |
|---|---|---|---|---|
| T0 | ~1.0s | overlay | 自动溶解 | 是（点击即过） |
| T1 | ~1.3s | overlay | 自动溶解 | 是 |
| T2 | ~1.8s | overlay / 半屏 | 自动溶解 | 是 |
| T3 | ~3.0s | 全屏 | 点击继续（或 5s 自动） | 是 |
| T4 | ~3.5s | 全屏 | 点击继续 | 是 |

### 四通道时间线（以 T1 为例）
```
t0ms     音效(完成音)  +  字标 scale-in  +  微粒子
t+300ms  人声(教练话术) +  副标文字淡入
t+600ms  粒子 settle
t+1300ms 溶解 → 下一屏
```
要点：**音效与人声错开 ~300ms**，避免糊在一起；T3/T4 时间线整体拉长、粒子持续。

## 7. 触发与后端事件映射

| 环节 | 后端 | 说明 |
|---|---|---|
| 完成一组（收口点） | `CourseInstanceMessageHandler#sendSetCompletedMessage(status=1)` | 计次(计数达标自动)/计时 两路都汇聚于此 |
| 定档所需数据 | `OpSumBo`（trainNumberBest/weightBest）+ `getPerformanceFromCache`（perfect占比） | 完成瞬间已就绪 → 可判 T0/T1/T2 |
| 完成整节课 | 课程结束流程（END 阶段） | 判 T3/T4 |
| 下发庆祝指令 | 新增 `CompletionCelebrationService` → 组装 `{tier, text, sfxCode, uiVariant}` 消息 → `MessageSender` | 前端据此渲染 |
| 跳转 | `doNext()` → REST（报告）或课程总结 | 上下文分支 |

**定档伪代码**
```text
function decideTier(scope, sum, perf, courseStats):
    if scope == COURSE:
        return isGrand(courseStats) ? T4_COURSE_GRAND : T3_COURSE_DONE
    // scope == SET
    if not reachedGoal(sum):              return T0_SET_ACK        // 打断/未达标
    if sum.trainNumberBest or sum.weightBest
       or perfectRatio(perf) >= 0.6:      return T2_SET_HIGHLIGHT  // 破纪录/优秀
    return T1_SET_DONE                                             // 普通达标
```

## 8. 意图分级与话术（扩展意图层）

本功能把[主 PRD]的意图层从 `意图 = f(表现)` 升级为 **`意图 = f(层级 scope, 质量 quality)`**：

| 意图 Intent | 话术池 TextCategory | 复用/新增 |
|---|---|---|
| `SET_ACK` | `CELEBRATE_SET_ACK` | 新增（安抚中性） |
| `SET_DONE` | `ENCOURAGE_PERFORMED_NOT_WELL` | 复用（中性口径） |
| `SET_HIGHLIGHT` | `ENCOURAGE_PERFORMED_WELL` / `ENCOURAGE_RECORD_BREAKING` | 复用 |
| `COURSE_DONE` | `CELEBRATE_COURSE_DONE` | 新增 |
| `COURSE_GRAND` | `CELEBRATE_COURSE_GRAND` | 新增 |

- **防重复**：沿用[需求一]的**洗牌袋**（每课程 × 每意图），一池用完才可能再现。
- **秒出 & 缓存**：话术走固定文案 → TTS 命中 OSS 缓存；起服预热。
- **话术草稿**：T1/T2 见 [需求一 §4](./req1-set-completion-celebration.md)；T0/T3/T4 见本文附录 B。

## 10. 边界与异常

| 场景 | 处理 |
|---|---|
| 反向取消 logset（status=0） | **不放庆祝**；已在展示则中止 |
| 最后一组（无 REST） | 庆祝后直接进课程总结（→ T3/T4 或 T1 后接课程总结） |
| 用户中途跳过/退出 | 立即结束庆祝，正常跳转；音效/人声打断 |
| 快速连续完成 | 庆祝去抖：同一 totalOrder 只触发一次 |
| 静音/勿扰 | 尊重系统与 App 音开关；无声时 UI 动效仍完整 |
| 话术池为空/多语言缺失 | 降级：仅 UI+音效，人声跳过，不报错 |
| 网络/TTS 失败 | 人声降级跳过；UI+音效不受影响 |

## 11. 埋点与指标

- 各档**触发次数与占比**（T0–T4）。
- 完成 → 庆祝首帧延迟（目标 P90 < 300ms）。
- **跳过率**（按档）：过高说明太长/太频 → 调时长或降频。
- 话术重复率（同课程内）。
- 体验 A/B：完课率、次日留存、组间流失。

---

## 12. 灰度与降级

- 总开关 `SysConfigs`（可一键关，回退到当前无庆祝行为）。
- 分档开关（如先只上 T2/T3/T4 大成就，普通档 T1 后置）。
- 通道级降级：人声失败→仅 UI+音效；音效关→仅 UI。

## 13. 开放问题

- **Q1** T0 是否需要庆祝页，还是直接进休息 + 仅一句安抚人声？（避免"没做完还弹页"的违和）
- **Q2** T3/T4 与课后报告页的关系：庆祝是独立前置页，还是课程总结页的入场动画？
- **Q3** "整节课高完成度(T4)"的判定阈值（PB 数量 / perfect 占比 / 完课率）需产品定标。
- **Q4** 全屏档默认自动前进还是必须点击？（自动更顺，点击更有掌控感）
- **Q5** 音效/人声/动效三通道，静音场景下人声是否转字幕气泡强化。

## 附录 B · T0/T3/T4 话术草稿（简洁·有温度）

**T0 安抚（`CELEBRATE_SET_ACK`）**
> 这组先记下，喘口气~ / 没关系，稳住节奏，下一组来。 / 记上了，休息一下再战。 / 尽力就好，缓一缓。

> 全部完成，今天很棒！ / 这节课拿下了，为你骄傲。 / 收工！坚持到底就是胜利。 / 练完啦，给自己鼓个掌。

**T4 满贯（`CELEBRATE_COURSE_GRAND`）**
> 满贯表现，今天封神！ / 全程高质量，太强了！ / 完美收官，这就是最好的你。

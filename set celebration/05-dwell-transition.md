# 05 · 停留与跳转逻辑

> 对应需求问题 4：庆祝页停留 ~2s（必要时更久），之后跳到下一个业务页——可能是"休息"、"课程结束数据"、或"直接结束退出"。

## 1. 停留时长

| 场景 | 默认停留 | 结束方式 |
|---|---|---|
| 本组完成（overlay 小庆祝） | **2.0s** | 到时自动溶解 |
| 破纪录 PB | 2.4s（略久，让高光沉淀） | 自动溶解 |
| 结课 / 满贯（全屏大庆祝） | **≥3.0s，或等点击** | 自动 or 点击继续 |
| 用户点击 | 立即结束 | 手动跳过 |

规则：
- **最短停留** ~1.2s：即使用户狂点，也保证动效/音效不被"秒切"显得突兀（可配）。
- **可跳过**：点击立即进入下一页（打断音效/语音）。
- **时长可配**：`dwellMs` 由档位给默认值，运营可调。

## 2. 跳转去向（按上下文决定，不写死）

庆祝页**本身不决定去哪**，它结束时回调 `onDone`，由课程状态机路由：

```
              ┌─────────────── 庆祝页结束 onDone ───────────────┐
              ▼                                                   │
        是本节课最后一个完成?                                     │
         │是                    │否                               │
         ▼                      ▼                                 │
   用户选择退出?           进入【组间休息 / 组间报告】           │
    │是        │否              (下一组的 rest 页)                │
    ▼          ▼                                                  │
【结束退出】 【课程结束数据页】                                   │
             (总结/AI报告)                                        │
```

三个去向：
1. **组间休息 / 报告**：中间组完成 → 进入 rest（对应组间语音 PRD 需求二）。
2. **课程结束数据页**：最后一组 / 整节课完成 → 课程总结（统计、AI 报告）。
3. **结束退出**：用户在结课后选择退出，或中途主动结束训练。

## 3. 状态机伪代码

```text
function onCelebrationDone(ctx):
    if ctx.userQuitRequested:
        goto EXIT                         // 直接结束退出
    elif ctx.isCourseEnd:                 // 最后一个/整节课完成
        goto COURSE_SUMMARY               // 课程结束数据页
    else:
        goto REST                         // 组间休息/报告

// 庆祝页驱动
function showCelebration(tier, ctx):
    render(tier)                          // UI + 撒花 + 音效 + 预生成语音
    dwell = tier.dwellMs                  // 2000 / 2400 / 3000...
    on tapOrTimeout(min=1200, max=dwell): // 可跳过、但有最短停留
        stopMedia()                       // 打断动效/音效/语音
        onCelebrationDone(ctx)
```

## 4. 边界

| 场景 | 处理 |
|---|---|
| 反向取消 logset（status=0） | 不弹庆祝；已弹则立即收起，不跳转逻辑变化 |
| 快速连续完成 | 同一 totalOrder 去抖，只弹一次 |
| 结课途中断网 | 庆祝照常（本地）；课程数据页再拉取，庆祝不阻塞 |
| 设备端 vs 手机端 | 停留/跳转逻辑一致；仅视觉按形态适配 |
| 全屏档"等点击"超时 | 设兜底自动前进（如 8s），避免卡死在庆祝页 |

## 5. 与设备/App 的分工

- **设备端（圆屏）**：训练主战场，庆祝 + 跳转 rest/summary 都在设备上完成。
- **手机 App**：可镜像/陪伴展示；跳转逻辑同源（由课程状态机统一驱动），避免两端各写一套。

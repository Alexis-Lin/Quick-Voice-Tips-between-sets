## 1. 目标
用户每完成一组/一节课时，给一个**分级的小高潮**（UI+音效+人声），即时、有仪式感、一致又有惊喜、不打断心流。**所有完成都值得庆祝**（含未达标的"已记录"）。

## 2. 体验流程
```
① 技术确认(末次动作动画,含逐次"咚咚") → ② 庆祝小高潮页(UI+音效+人声) → ③ 跳转(休息/结课数据/退出)
```
触发收口点：完成一组事件（后端 `sendSetCompletedMessage(status=1)`，计次/计时两路汇聚）；完成瞬间表现/PB 数据已就绪，可据此定档。

## 3. 解耦组合模型（不穷举）
把状态拆成正交维度，运行时组合，而非每档写死一套：

| 维度 | 取值 |
|---|---|
| **D1 范围** | 本组 SET / 本动作 ACTION / 全部 COURSE |
| **D2 状态** | 已记录 LOGGED（未达标）/ 已完成 DONE（达标） |
| **D3 表现** | 无 / 很棒 GREAT / 新纪录 PB（走独立徽章，不进正文） |

## 4. 三通道如何组合

| 通道 | 组合规则 |
|---|---|
| **UI 文字** | 三行：D1 范围(小·上) + **D2 状态(最大·中)** + D3 表现(徽章·下)；多语言按词元拼接 |
| **撒花/动效** | 数量 = f(范围)×f(表现)；金色 = 表现≠无；圆屏光环随范围/PB 增强；纯代码无素材 |
| **音效** | 基础音 base(范围,状态)：已记录=咚咚 / 已完成=当当(范围越大越隆重) ＋ 叠层：PB=啪啪 |
| **人声** | 按桶(范围×状态×表现)预生成、洗牌袋挑一条；**只播不上屏**；不实时合成 |

**默认全部庆祝**，只有 PB 多一层「啪啪」+ 金色；GREAT 视觉为主不叠音。

组合示例：

| 范围 | 状态 | 表现 | 文字(三行) | 音效 |
|---|---|---|---|---|
| 本组 | 已完成 | 无 | 本组 / 已完成 | 当当 |
| 本组 | 已完成 | 新纪录 | 本组 / 已完成 / 新纪录 | 当当+啪啪 |
| 本组 | 已记录 | 无 | 本组 / 已记录 | 咚咚 |
| 全部 | 已完成 | 新纪录 | 全部 / 已完成 / 新纪录 | 当当·和弦+啪啪 |

## 5. 一致性
- **恒定层 L0（两端一致）**：荧光绿×黑、字标、撒花样式、声音签名、教练人声人格。
- **组合层（惊喜）**：范围/状态词元、表现徽章、音效叠层、撒花强度、圆屏光环 vs 手机全屏。

## 6. 独立原子模块（不拥有导航）
庆祝界面是**自包含原子模块**：给定 config 就独立演完一次庆祝，**不决定去哪**——演完发 `onDone`，去向（休息/结课数据/退出）由当时业务逻辑决定。停留时长可由宿主 `dwellMs` 控制。详见 [`05-atomic-module.md`](./05-atomic-module.md)。

## 7. 载体形态（两端）

| 端 | 形状 | 布局要点 |
|---|---|---|
| **设备端（主）** | 纯圆 466×466 | 内容收进圆内**安全区**（内接正方 ≈ 直径/√2 ≈ 329px）；撒花圆形裁剪；**圆边光环**替代全屏爆发 |
| **手机 App** | 竖向方屏 | 空间更足，字标更大 |

恒定层（荧光绿×黑/字标/撒花/声音签名/人声人格）两端一致；仅布局（安全区/字号/光环 vs 全屏）按形态适配。设计图见 [`ui-states/`](./ui-states)。

## 8. 触发与定档（后端）

- 收口点：`sendSetCompletedMessage(status=1)`（计次达标自动 / 计时到点 两路汇聚）。
- 完成瞬间 `OpSumBo`(PB) + 评分缓存(perfect占比) 已就绪 → 可定 ①②③。

```text
scope = SET | ACTION | COURSE            // 由完成层级决定
state = reachedGoal ? DONE : LOGGED      // 是否达标
perf  = (trainNumberBest||weightBest) ? PB
      : (perfectRatio >= 0.6)          ? GREAT
      :                                  NONE
```

## 9. 四通道时间线（示例）
```
t0     撒花喷发 + 状态词入场 + 完成音效(base)
t+90   状态词弹出到位
t+300  徽章跳入 + 预生成语音播放(不上屏; PB 叠「啪啪」音效)
t+dwell 溶解 → 发 onDone（去向由宿主决定）
```
错峰原则：音效 t0、人声 t+300ms，避免糊在一起。

## 10. 埋点与灰度
- **埋点**：各 case 触发占比；完成→庆祝首帧延迟(目标 P90<300ms)；跳过率(按 case)；语音重复率；TTS 缓存命中率。
- **灰度**：总开关 `SysConfigs` 可一键关（回退无庆祝）；可按 case/端分批放量；通道级降级（人声失败→仅 UI+音效）。

## 11. 边界
反向取消(status=0)不弹；快速连续去抖(同 totalOrder 只弹一次)；最后一组无休息→宿主在 onDone 去结课页；静音仍保留 UI 动效；话术池空则跳过人声不报错；全屏"等点击"设 ~8s 兜底自动前进。

## 12. 开放问题
- Q1 范围维度是否需要"本动作"这一档（若无真实节点则砍为 本组/全部）。
- Q2 静音场景是否把语音文案转字幕气泡。
- Q3 结课数据页与庆祝页是分离前置页，还是数据页的入场动画。
- Q4 数字是否进语音（默认不进，见 [`04-voice-copy.md`](./04-voice-copy.md) §3）。

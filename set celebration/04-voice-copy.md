# 04 · 庆祝语音：预生成方案 + 文案

> 对应需求问题 3：语音要**提前生成好**（不实时 TTS，避免延时）；可**一定程度**依赖次数/完成情况，但不要太依赖；文案**有多样性、不要太短**。

## 1. 核心策略：预生成 + 运行时只挑选播放

**不做实时 TTS。** 语音在**离线批量**生成成音频文件，设备/App 侧运行时只做"选一条 + 播放"，延时 ≈ 0。

关键取舍：**不要把"具体次数"烧进单条语音**——否则每个数字都要一条、且强依赖实时数据。改为：

- 语音只依赖**粗粒度的完成情况桶**（= 解耦维度的组合：范围 × 状态 × 表现），这些在完成瞬间已知，且数量有限。
- **每个桶预生成 N 条不同文案**（多样性），运行时用**洗牌袋**随机挑一条，不连续重复。
- 次数等精确数字交给 **UI 文字/徽章**去呈现（视觉不怕数字），语音保持"生动但不含精确数值"。

> 这样既"提前生成"，又"一定程度贴合完成情况"（桶已经区分了达标/破纪录/结课），但"不过度依赖"精确次数。

## 2. 桶的划分（有限、可预生成）

桶 = 关键维度组合，控制在十几个以内：

| 桶 ID | 触发 | 语气 |
|---|---|---|
| `SET_LOGGED` | 本组·未达标 | 肯定、鼓励继续 |
| `SET_DONE` | 本组·达标 | 轻快认可 |
| `SET_GREAT` | 本组·表现优秀 | 称赞质量 |
| `SET_PB` | 本组·破纪录 | 兴奋、庆祝 |
| `ACTION_DONE` | 某动作全部组完成 | 阶段小结 |
| `COURSE_DONE` | 整节课完成 | 收官、致敬坚持 |
| `COURSE_GRAND` | 整节课·多PB/高质量 | 史诗、满贯 |

每桶 **8~15 条**变体 × 语言 → 总量约 `12桶 × 12条 × N语言`，几百条，离线一次性生成、存 OSS/设备 flash 完全可控。

## 3. 需要"贴数字"时怎么办（可选，克制使用）

若某些高光时刻想报出数字（如"这组 12 次，破纪录！"）：

- **方案 A（推荐）**：仍用不含数字的整句（"又破纪录了，太强了！"），数字交给 UI。零拼接、最自然。
- **方案 B（仅 PB 等少数场景）**：预生成**数字片段**（0–50 的独立音频）+ 句子前后段，运行时拼接 `[前段] + [数字] + [后段]`。能报数字但有拼接感，且要控制韵律；只在少数关键场景用。

默认走 A，B 作为后续增强。

## 4. 预生成流水线

```
文案表(csv: 桶, 语言, 文本, 变体id)
      │  离线批量
      ▼
批量 TTS(ElevenLabs / 火山 等) ──► 音频文件(opus/mp3)
      │
      ▼
索引: {桶}/{语言}/{变体id}.opus  ──► 上传 OSS / 打包进设备固件
      │  运行时
      ▼
完成事件 → 定桶 → 洗牌袋挑变体id → 播放本地/CDN音频（无实时合成）
```

- **设备端**：庆祝语音包随固件预置或按需下载到 flash；opus 压缩，单条 2–4s，总包体可控。
- **App 端**：走 OSS/CDN 缓存，首次拉取后本地缓存。
- **更新**：文案表改动 → 重跑流水线 → 增量替换，代码不动。

## 5. 文案草稿（多样、不太短；中英各示例，运营可扩到每桶 12+）

> 长度目标：一句完整、带点温度和画面感，约 8–20 字，不是"完成！"这种一词短语。

**SET_DONE（本组达标）**
- 这组稳稳拿下，节奏保持得很好，喘口气继续。
- 完成！动作很到位，放松一下肩膀准备下一组。
- 干得漂亮，这组质量在线，休息片刻我们接着来。

**SET_GREAT（本组优秀）**
- 这组几乎组组到位，控制力很棒，保持住这个状态。
- 又稳又准，动作标准得像教科书，非常出色。

**SET_PB（本组破纪录）**
- 破纪录啦！你刚刚超越了自己，这一组值得记住。
- 新高度达成，全力以赴的样子太帅了，为你鼓掌！

**SET_LOGGED（未达标，仍鼓励）**
- 这组先记下，尽力就好，调整呼吸我们下组再战。
- 没关系，稳住节奏，坚持本身就已经很了不起。

**COURSE_DONE（结课）**
- 全部完成，今天这节课你坚持到底了，真的很棒。
- 练完啦，从头到尾的努力都算数，给自己鼓个掌。

**COURSE_GRAND（满贯）**
- 满贯表现，全程高质量，这就是最好的你，太强了！
- 完美收官，今天几乎无可挑剔，这份坚持值得骄傲。

（英文桶对应各配 8–15 条，逻辑同。）

## 6. 与其它通道的关系

- **不上屏**：语音只播、UI 不写这句话（UI 三行已表达"什么·状态·表现"）。
- **与音效错峰**：完成音效 t0 起，语音 t+300ms 起，避免糊在一起。
- **静音/无障碍**：可选把当前桶的文案作为字幕气泡显示（见 05 停留逻辑 / 开放问题）。

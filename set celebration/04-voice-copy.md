# 04 · 庆祝语音：预生成方案 + 短/长文案

> 需求：语音**提前生成好**（不实时 TTS，零延时）；**解耦实际组间的纠错/统计结果**（主要为保速度，也便于预生成），可保留一点丰富性；先出**中文**、**短/长两种**。

## 1. 核心策略

1. **预生成、不实时合成**：离线批量把文案跑成音频，运行时只"挑一条 + 播放"，延时≈0。
2. **解耦统计**：文案**不引用**本组的具体纠错项、perfect/good 次数等**实时统计**——那些交给 UI 呈现。语音只依赖**极粗的完成标记**（完成 / 破纪录 / 结课 这种布尔/枚举，完成瞬间就有），保证既能提前生成、又不必等数据。
3. **短/长两档**：每种情境备**短**（一句爆发）和**长**（一句完整、暖一点）两版；按**停留时间**选：停留短用短版，停留够长用长版。
4. **多样性**：每档多条变体 + 洗牌袋随机挑，防重复。

## 2. 长度与时间

- 中文舒适语速约 **5–7 字/秒**。
- **长版上限 ~18–20 字**（≈2–3 秒说完，正好卡住界面停留），**短版 2–6 字**。
- 目标：最长的也在 2–3s 内说完，不拖过停留。

## 3. 文案（中文 · 短/长）

> 情境只用"完成/破纪录/未达标/结课/满贯"这种粗标记，**不含具体数字与纠错**。每档可继续扩到 10+ 条。

### 本组完成（最常用）
**短**：完成！ / 漂亮！ / 稳了！ / 干得好！ / 这组拿下！
**长**：
- 这组稳稳拿下，节奏保持得很好。
- 完成！动作很到位，喘口气继续。
- 干得漂亮，这组质量在线，继续保持。
- 好样的，这组很扎实，放松一下。

### 本组 · 破纪录
**短**：破纪录！ / 新纪录！ / 超越自己！ / 太强了！
**长**：
- 破纪录啦，你刚刚超越了自己！
- 新高度达成，这一组值得记住！
- 全力以赴的样子真帅，为你鼓掌！
- 又刷新纪录了，今天状态在线！

### 本组 · 未达标（已记录，仍鼓励）
**短**：记下了！ / 先记一笔！ / 稳住！
**长**：
- 这组先记下，调整呼吸下组再战。
- 没关系，稳住节奏，坚持就已经很棒。
- 尽力就好，喘口气我们继续。

### 整节课完成（结课）
**短**：全部完成！ / 收工！ / 练完啦！
**长**：
- 全部完成，今天你坚持到底了！
- 练完啦，这份努力都算数，真棒。
- 收工！从头到尾都很稳，给自己鼓掌。

### 整节课 · 满贯
**短**：满贯！ / 完美收官！
**长**：
- 满贯表现，今天几乎无可挑剔！
- 完美收官，这就是最好的你！

## 4. 预生成流水线

```
文案表(csv: 情境, 长度(短/长), 变体id, 文本)
   │ 离线批量 TTS(ElevenLabs / 火山 等)
   ▼
音频(opus/mp3)  →  索引 {情境}/{长度}/{变体id}.opus  →  OSS/CDN 或 设备 flash
   │ 运行时
   ▼
完成事件 → 定情境 + 按停留选长度 → 洗牌袋挑变体 → 播本地/缓存音频（无实时合成）
```

- 情境×长度×变体 数量有限，几百条，离线一次生成即可；文案改动 → 重跑流水线，代码不动。
- **不上屏**：语音只播、UI 不写（三行文字已表达"什么·状态·表现"）。
- **与音效错峰**：完成音效 t0 起，语音 t+300ms 起。

## 5. 可选增强（不破坏"解耦/预生成"）
- **轻依赖布尔标记**即可切情境（完成/PB/结课），无需实时统计。
- 若某天想报数字（如"破纪录"时说次数）：预生成 0–50 数字片段做**拼接**，仅少数高光场景用，默认不做（见旧版 §3）。
